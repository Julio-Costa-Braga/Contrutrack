# Contribuir para o ConstruTrack

Obrigado por considerar contribuir para este projeto.

## Fluxo recomendado

1. Faça um fork do repositório.
2. Crie uma branch para a sua alteração.
3. Implemente e teste a mudança localmente.
4. Abra um pull request com descrição clara do problema e da solução.

## Regras gerais

- Mantenha o código legível e bem documentado.
- Atualize a documentação quando introduzir mudanças relevantes.
- Não submeta ficheiros com secrets ou configurações locais.
