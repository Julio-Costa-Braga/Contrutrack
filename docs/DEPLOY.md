# Deploy

## Vercel

1. Crie um projeto no Vercel.
2. Conecte este repositório GitHub.
3. Defina as variáveis de ambiente indicadas em [SETUP.md](SETUP.md).
4. Faça deploy.

## Supabase

- Garanta que os ficheiros SQL foram aplicados.
- Crie os buckets de storage indicados no README principal.
- Configure as políticas de storage e RLS conforme necessário.
